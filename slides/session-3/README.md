# Session 3 - The board in KiCad

60 minutes. Course weeks 4, 7. Learning outcomes 2 and 3.

## Topics

Reading a schematic, connecting the ESP32-S3 on headers, footprints and placement, Kelvin sensing, trace width, decoupling, return paths and grounding, power rails and protection, ERC and DRC, antenna keep-out, power budget for battery devices, hardware for running models.
