# slides

Slides for the four one-hour sessions. Each session folder holds the deck and a README with the agenda, the demos it needs and the files to export.

| Session | Title | Folder |
| ------- | ----- | ------ |
| 1 | The whole system | [session-1/](session-1/) |
| 2 | Circuit and firmware | [session-2/](session-2/) |
| 3 | The board in KiCad | [session-3/](session-3/) |
| 4 | End to end | [session-4/](session-4/) |

Conventions:

- File names follow the pattern session-N-title.pptx, with a PDF export next to it.
- Example numbers on slides are labelled as examples. Measured values come from our own runs and are filled in before the session.
- Wi-Fi names, passwords and IP addresses are removed from screenshots and clips.
- Share the repository link with students only after the instructor has approved it.
