# Session 1 - The whole system

60 minutes. Course weeks 1, 5, 6. Learning outcomes 1 and 5.

## Agenda

| Time | Block |
| ---- | ----- |
| 0:00 - 0:15 | The loop and Industry 4.0 |
| 0:15 - 0:35 | The IoT and AI stack |
| 0:35 - 1:00 | The circuit, built live |

## Demos

- Clip 1 (Tinkercad): voltage divider, shunt and op-amp feeding analog inputs; serial monitor prints volts, amps and watts
- Clip 2 (Tinkercad): MOSFET switching a motor with an upper and a lower power limit
- Clip 3 (bench): whole system running, a load added, alert raised, load cut

The Tinkercad build uses an Arduino as a stand-in for the ESP32-S3 (5 V, 10-bit ADC). Tinkercad cannot do Wi-Fi, MQTT or the model, so those are shown on the real hardware.
