# Session 2 - Circuit and firmware

60 minutes. Course weeks 1, 4, 7. Learning outcomes 2 and 3.

## Topics

Embedded constraints, ADC, filtering, calibration, current sensing, MOSFET switching, powering the board, firmware structure, features and data for a model, where the model runs.

## Demos

- Clip 1 (Tinkercad): noisy input and a moving average, serial plotter showing both
- Clip 2 (bench): sensor reading against a multimeter at three load levels
- Clip 3 (Tinkercad): motor switched off with and without a flyback diode, oscilloscope on the drain

Bench numbers on the slides must come from our own measurements. Delete any row that was not measured.
