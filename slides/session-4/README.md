# Session 4 - End to end

60 minutes. Course weeks 7, 9, 10, 11, 12. Learning outcomes 3, 4, 5 and 6.

## Topics

Physical build, MQTT, protocol choices (MQTT, CoAP, Profinet, WirelessHART, M2M and M2C), dashboard, machine learning workflow, two anomaly detectors, results on injected faults, closing the loop, reliability, edge against cloud, operations, cybersecurity, Industry 5.0 and cobots, V2V and AIoT, scaling up, limits of the project.

## Demos

- Clip 1: the physical build
- Clip 2: terminal subscribed to the topic, then the dashboard updating
- Clip 3: fault caused on the bench and caught
- Clip 4: power budget exceeded, command published, MOSFET switches the load off

Safety: low-voltage DC only. Faults are caused by adding a resistor in parallel, loading a small fan lightly or unplugging the load. No shorts.
